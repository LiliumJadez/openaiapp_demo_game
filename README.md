## 🌊 游戏简介

《虚数海筏》是一款基于 [OpenAI Apps SDK](https://developers.openai.com/apps-sdk/) 开发的网页游戏。玩家扮演在虚数海上漂泊的垂钓者，每一次垂钓都会遭遇由 AI 实时生成的神秘生物，并需要做出道德抉择。

### 核心玩法

1. **动态垂钓**：在 Canvas 绘制的动态湖面场景中点击抛竿
2. **AI 生成生物**：GPT-4o 根据天气状态实时生成具有独特属性的鱼类
3. **视觉卡牌**：DALL-E 3 为每条鱼生成独特的视觉卡牌
4. **道德抉择**：面对每条生物的求饶或诱惑，做出不可逆的选择
5. **业力系统**：隐性业力值决定最终结局
6. **流式叙事**：使用 Streaming 技术生成个性化结局

## 🎮 游戏机制

### 🌊 第三人称视角

游戏采用第三人称视角，玩家可以看到一个像素风格的小人坐在孤舟上垂钓。场景包含：

- **像素小人**：戴着斗笠的垂钓者，会根据钓鱼状态做出不同动作
- **孤舟**：随波浪轻轻摇晃的木船
- **动态水面**：使用多层波浪和涟漪效果模拟虚数海
- **粒子系统**：根据天气呈现不同的粒子效果（雨滴、雾气、极光等）

### 🎯 点击区域系统

水面被划分为不同的点击区域，不同区域有不同的反馈和稀有度加成：

| 区域类型 | 位置 | 稀有度加成 | 视觉提示 |
|---------|------|-----------|---------|
| 浅水区 | 船只附近 | 无 | 淡蓝色光晕 |
| 深水区 | 较远处 | +20% | 深蓝色光晕 |
| 神秘区域 | 边缘角落 | +50% | 紫色光晕 |

鼠标悬停时会显示区域光晕，帮助玩家选择最佳垂钓位置。

### ⛅ 动态天气系统（7种天气）

天气保持**随机性**，但会**受到玩家状态的影响**。每次抛竿都可能触发天气变化：

| 天气 | 图标 | 描述 | 触发倾向 |
|------|-----|------|---------|
| 晴空 | ☀️ | 阳光穿透水面 | 初始/平衡状态 |
| 血雨 | 🩸 | 血色细雨飘落 | 暴食值高 |
| 迷雾 | 🌫️ | 万物隐匿其中 | 金币过多 |
| 风暴 | ⛈️ | 雷电撕裂边界 | 贪婪值高 |
| 极光 | 🌌 | 梦幻交织 | 慈悲值高 |
| **日蚀** | 🌑 | 天地晦暗 | 极端暴食/贪婪 |
| **星陨** | 💫 | 星辰坠落 | 高慈悲/平衡 |

**天气影响因素**：
- 业力值会增加对应天气的出现概率（非强制）
- 捕获数量越多，稀有天气（日蚀、星陨）出现几率越高
- 天气变化有随机波动，保持游戏的不确定性
- 状态面板会显示天气趋势预测

**平滑过渡**：
- 天气变化采用3秒渐变过渡，不再瞬间切换
- 天空颜色、水面颜色、粒子效果同步过渡
- 视觉体验更加自然流畅

### 📜 生物故事

每个虚数生物都有完整的身世故事（50-100字），包含：

- **过去**：它曾经是什么？经历过什么？
- **执念**：它最放不下的是什么？有什么遗憾？
- **美好记忆**：它最珍贵的回忆是什么？
- **现在与未来**：它如何看待当下？对未来有什么期待？

故事以散文诗的形式呈现，每次捕获都是独一无二的叙事体验。选择"放生"可以获得生物透露的情报线索。

### 🎣 钓鱼博弈系统

钓鱼不再是简单的等待，而是需要技巧的博弈过程：

**操作方式**：
- 按住屏幕/鼠标：拉扯鱼线，增加张力
- 松开：释放张力，让鱼线松弛

**博弈要素**：
- **目标区域**：将鱼拉入绿色安全区
- **鱼线张力**：保持在合适范围内（绿色指示）
- **捕获进度**：鱼在安全区且张力合适时增加

**注意事项**：
- 张力过高（>90%）会导致鱼线断裂
- 张力过低（<10%）会让鱼逃脱
- 稀有度越高的生物，挣扎越剧烈，安全区越小

### 🐟 稀有度差异化

不同稀有度的生物有完全不同的博弈难度：

| 稀有度 | 等待时间 | 挣扎强度 | 安全区大小 | 特效 |
|-------|---------|---------|-----------|------|
| 普通 | 1-2秒 | ⚡ | 大 | 无 |
| 稀有 | 1.5-2.5秒 | ⚡⚡ | 较大 | 绿色光晕 |
| 珍稀 | 2-3秒 | ⚡⚡⚡ | 中等 | 蓝色光晕 |
| 史诗 | 2.5-4秒 | ⚡⚡⚡⚡ | 较小 | 紫色光晕 |
| 传说 | 3-5秒 | ⚡⚡⚡⚡⚡ | 小 | 金色光晕+粒子 |
| 神话 | 4-6秒 | ⚡⚡⚡⚡⚡⚡ | 极小 | 粉色闪烁+全屏粒子 |

### 🎲 抉择系统

| 选择 | 效果 | 业力影响 | 天气趋势 |
|------|------|---------|---------|
| 🔥 消化 | 恢复体力 | 暴食值 + | → 血雨 |
| 💎 收藏 | 获得金币 | 贪婪值 + | → 风暴 |
| 🕊️ 放生 | 获取情报 | 慈悲值 + | → 极光 |

### 🔮 五种结局

- **沉沦结局**：暴食值过高，灵魂被吞噬，伴随持续的血雨
- **贪婪结局**：贪婪值过高，财富成为囚笼，风暴永不停歇
- **觉悟结局**：慈悲值过高，获得超脱，极光永远照耀
- **平衡结局**：三者均衡，成为观察者，天气晴朗明媚
- **虚无结局**：体力耗尽，在迷雾中消散

### 📖 图鉴系统

收集并记录你遇到的每一种虚数生物：

- **自动记录**：每次捕获新生物自动添加到图鉴
- **多维度统计**：记录捕获次数、稀有度变体、出现天气
- **故事收集**：保存每个生物最精彩的身世故事（50-100字）
- **图像展示**：展示 AI 生成的生物卡牌图像
- **持久化存储**：图鉴数据本地保存，刷新不丢失

### 🏆 成就系统

解锁成就，证明你的垂钓技艺：

| 类别 | 示例成就 | 解锁条件 |
|------|---------|---------|
| 📚 收集 | 初入虚数海 | 捕获第一条生物 |
| 📚 收集 | 神话具现 | 捕获神话稀有度生物 |
| 📚 收集 | 博物学家 | 发现25种不同生物 |
| ⚖️ 业力 | 平衡之道 | 三种业力值保持相近 |
| 🌊 探索 | 日蚀见证者 | 在日蚀中捕获生物 |
| ✨ 特殊 | 慈悲为怀 | 连续放生5条生物 |

成就系统契合生成式玩法特点：
- 鼓励探索不同天气、稀有度
- 追踪玩家行为模式（连续选择同一选项）
- 平衡业力值也能获得成就
- 成就进度本地保存

## 🚀 快速开始

### 环境要求

- Node.js 18+
- npm 或 pnpm
- OpenAI API Key

### 安装

```bash
# 克隆项目
git clone https://github.com/your-username/imaginary-sea-raft.git
cd imaginary-sea-raft

# 安装依赖
npm install

# 配置环境变量
cp env.example .env
# 编辑 .env 文件，填入你的 OpenAI API Key
```

### 开发模式

```bash
# 同时启动前端和后端
npm start

# 或分别启动
npm run dev      # 前端 (端口 3000)
npm run server   # 后端 (端口 3001)
```

访问地址：
- **游戏主页**：http://localhost:3000/
- **配置控制台**：http://localhost:3000/config.html

#### 🎛️ 配置控制台

配置控制台是一个独立的网页界面，用于调整游戏的所有参数：

- **稀有度概率**：调整不同稀有度鱼类的出现概率
- **业力系统**：设置业力阈值和触发条件
- **钓鱼难度**：精细调整每个稀有度的钓鱼小游戏参数
- **结局触发**：修改各种结局的触发条件
- **🎵 BGM音乐**：配置天气和结局的背景音乐路径
- **AI提示词**：查看和编辑AI生成内容的提示词（需在代码中同步修改）

配置可以导出为JSON文件保存，也可以导入之前的配置。

#### 🎵 BGM 音乐系统

游戏支持为不同天气和结局配置背景音乐：

1. **音频文件放置**：将音频文件放在 `public/audio/` 目录下
2. **配置路径**：在配置控制台的"🎵 BGM音乐"标签页中设置路径
3. **支持格式**：MP3、OGG、WAV 等浏览器支持的音频格式
4. **丝滑切换**：音乐切换时会自动进行2秒的交叉淡入淡出
5. **快捷键**：按 M 键快速静音/取消静音

详细说明请参考 `public/audio/README.md`。

## 🎨 新功能特性

### 🖼️ 图片缓存系统

游戏使用 IndexedDB 自动缓存已生成的鱼类图片：

- **自动缓存**：首次生成的图片会自动保存到本地
- **快速加载**：再次遇到相同鱼类时，直接从缓存加载图片（无需等待AI生成）
- **智能过期**：缓存7天后自动清理
- **降级处理**：如果 IndexedDB 不可用，自动降级到内存缓存
- **节省成本**：减少重复的图像生成API调用

缓存键基于：`鱼模板ID_稀有度_天气类型`，确保同一条鱼在不同条件下有不同的图片。

### 📊 结局行为总结

游戏结局时会显示详细的行为统计和评价：

**统计内容**：
- 捕获总数和图鉴完成度
- 收集价值（当前和历史最高）
- 行为倾向（消化/收藏/放生的比例）
- 业力指数分布
- 特殊标签统计（善良/邪恶灵魂的处理方式）

**动态评语**：
- 根据玩家行为生成个性化评价
- 如："饥饿的猎食者・灵魂吞噬者"
- 或："慈悲的放生者・博物学家"

## 🔧 技术架构

### 前端

- **React 18** + **TypeScript**：组件化开发
- **Tailwind CSS**：原子化样式
- **Framer Motion**：流畅动画
- **Zustand**：轻量级状态管理
- **Canvas API**：动态场景渲染

### 后端

- **Express.js**：API 服务器
- **OpenAI SDK**：AI 模型调用
- **Server-Sent Events**：流式输出

### AI 集成（成本优化版）

- **GPT-4o-mini**：生成鱼类属性、对话、结局叙事（比 GPT-4o 便宜 10 倍）
- **DALL-E 3**：生成风格化鱼类卡牌（标准质量，优化提示词）

**成本优化策略**：
- 使用 GPT-4o-mini 替代 GPT-4o（大幅降低文本生成成本）
- 限制 max_tokens 输出长度（鱼类 500 tokens，结局 400 tokens）
- 图像使用标准质量（standard）而非高清（hd）
- 简化图像提示词，使用风格化描述降低复杂度
- 鱼类生成包含 `visualKeywords` 字段，优化图像生成精度

## 🌐 部署到 ChatGPT

### 1. 部署应用

推荐使用 Vercel 一键部署：

【下方尚未更改链接】

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https://github.com/your-username/imaginary-sea-raft)

或使用 Docker：

```bash
docker build -t imaginary-sea-raft .
docker run -p 3001:3001 -e OPENAI_API_KEY=your_key imaginary-sea-raft
```

### 2. 配置 MCP Manifest

确保 `mcp-manifest.json` 中的 URL 指向你的部署地址：

```json
{
  "server": {
    "url": "https://your-domain.com/mcp",
    "transport": "sse"
  },
  "widget": {
    "url": "https://your-domain.com",
    "width": 800,
    "height": 600
  }
}
```

### 3. 提交到 ChatGPT

1. 访问 [OpenAI Apps 开发者门户](https://platform.openai.com/apps)
2. 创建新应用
3. 上传你的 Manifest 配置
4. 按照 [App 提交指南](https://developers.openai.com/apps-sdk/deploy/submit-your-app) 完成审核
